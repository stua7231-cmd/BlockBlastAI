# BlockBlast AI 0.2 (experimental)
Open this directory in Android Studio, install Android SDK 35 and use JDK 17. Gradle sync, then Run on an Android 11+ device. No Gradle wrapper or APK is included. Android Studio can use a local Gradle 8.9 installation. The Android build has not been verified here.
Enable the BlockBlast AI accessibility service in Settings, then open the game. Hint only calculates a move; Auto sends gestures; Stop cancels future gestures. Disable the service when finished. Use only where permitted by game rules.
Calibration: boardX/Y are the top-left board coordinates divided by full screenshot width/height; boardSize is board width / screen width; trayY is tray center / screen height; trayCell is tray block width / screen width; dragOffset is vertical finger-to-piece offset / screen height; emptyColor is sampled empty board cell color. Defaults are guesses, not measured from Block Blast. Detection is experimental, including centered tray assumptions. Hint numbers refer to detected pieces from left to right, not necessarily original slots. Auto stops when next board differs from predicted board. The overlay may interfere with screenshots if it covers game content. Only known package names or names containing blockblast trigger overlay; adjust package detection if needed.
Solver uses an 8x8 bitboard and beam search (240 states), line clearing and a board-space heuristic. It does not predict future pieces or guarantee a score. No network access or image upload. Pure Java solver smoke-tested; screenshot detection, Android compilation and gesture behavior not tested on a device.

V0.2: original local solver inspired by public batch-search and combo planning approaches, not an integration of external website code or API. Uses estimated multi-line and within-hand streak bonuses, near-full lines and free 3x3 regions. No verified game score model. Reference: https://github.com/zacharygoh/block-blast-solver and https://blockblastsolver.tools/how-it-works.

## Compilare fără Android Studio (v0.3)
Creează un repository GitHub gol și încarcă toate fișierele din arhivă, inclusiv .github/workflows/build.yml. În Actions > Build Android APK > Run workflow, pornește compilarea. Descarcă artifactul BlockBlastAI-APK și extrage app-debug.apk. Detectorul folosește coordonate inițiale din captura furnizată și estimarea culorii celulelor întunecate; nu este validat pentru toate temele. Testează Hint înainte de Auto.
